# Design System Document

## Brand & Style
The brand personality is direct, striking, and content-driven. We embrace a High-Contrast / Bold design movement characterized by loud colors, massive typography, and aggressive visuals designed to capture immediate attention.

## Colors
- **Primary:** `#ff0101` (High-impact red)
- **Secondary:** `#000000` (Stark black)
- **Tertiary:** `#ffffff` (Clean white)
- **Neutral:** `#ffffff` (Neutral white base)

## Typography
- **Font Family:** Inter (Headline, Body, Label)
- **Scale:** Bold headline weights paired with highly readable body copy.

## Layout & Spacing
- **Layout Model:** Fluid grid system with consistent spacing.
- **Spacing Scale:** Built on a 2x spacing rhythm.

## Elevation & Depth
- **Style:** Low-contrast outlines and bold borders providing crisp structural separation.

## Shapes
- **Roundedness:** Level `2` (Rounded), featuring 0.5rem base radii for friendly yet modern container geometry.

## Components
- Buttons, input fields, cards, and navigation elements utilize the high-contrast color scheme, Inter typography, and rounded container shapes for a cohesive user experience.
